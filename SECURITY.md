# Security policy

Please **do not open public issues for security problems.** Use GitHub's "Report a vulnerability" (private security advisory) on this repository instead.

Include steps to reproduce and the version you tested. We aim to respond within 7 days.

Operators: keep Node.js up to date, serve over https (`PUBLIC_URL=https://…`), back up `data/`, and set `ALLOW_SIGNUP=0` if the install is only for your own company.
